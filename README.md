
# Airline Passenger Satisfaction Prediction

## Overview
This project predicts airline passenger satisfaction using
machine learning classification algorithms.

## Dataset
Kaggle: Airline Passenger Satisfaction
https://www.kaggle.com/datasets/teejmahal20/airline-passenger-satisfaction

## Project Steps
- Missing value handling
- Outlier detection using boxplots and IQR
- Categorical encoding
- Exploratory data analysis (EDA)
- Data visualization
- Train-test split and feature scaling
- Model training and comparison
- Cross-validation and evaluation

## Machine Learning Algorithms
1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier

## Evaluation Metrics
- Accuracy
- Cross-validation score
- Confusion matrix
- Precision, recall, and F1-score

## Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## How to Run
1. Download the notebook.
2. Download train.csv from Kaggle.
3. Install dependencies using `pip install -r requirements.txt`.
4. Run the notebook in Jupyter.

## Results
The notebook compares all three models. Actual
accuracy results are reported after running the experiments.
